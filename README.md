# full stack project

Should only require gcc, ghdl and whatever software needed to program the fpga.

Ideally, you only see c, vhdl(2008), and maybe 1 other scripting language in the languages section on github. for now i'm still using make, but will get rid of.

* rv32ima cpu, cache, mmu/tlb, floats
* c compiler: lexer, recursive descent parser, semantic checks, SSA/SoN, codegen
* build: build system used for the entire project, no makefiles.
* assembler
* linker
* libc
* os
* debugger
* render shell from a uart
* text editor
* smaug: python interpreter/jit
* games
* browser
